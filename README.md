## 📂 Project Showcase

### 1. 📐 Linear Algebra: Mapping & Transformations
Visualizing how linear mappings $f: \mathbb{R}^2 \to \mathbb{R}^2$ transform the standard basis using matrix representations $A \in \mathcal{M}_2(\mathbb{R})$.

- **Focus:** Basis transformations and geometric intuition.
- **Code:** [matrix_viz.py](./Linear-Algebra/matrix_viz.py)

![Matrix Transformation](./Linear-Algebra/transformation_plot.png)
*Red: Basis vector $e_1$ | Blue: Transformed image $f(e_1)$*

### 2. 📈 Calculus: Convergence of Taylor Series
Analyzing the local approximation of functions through Taylor-Young expansions.

- **Focus:** Understanding the radius of convergence and local behavior of transcendental functions like $\sin(x)$.
- **Code:** [taylor_sin_viz.py](./Calculus/taylor_sin_viz.py)

![Taylor Approximation](./Calculus/taylor_plot.png)
*Graph showing the convergence of polynomials toward the original function around $a=0$.*
